# Skill 6 — Assets de 4Geeks por tecnología

**Nombre:** `academy-4geeks-get-assets`

**Activación:** frases como «ubica en la lista de assets de 4Geeks todos los de Python», «busca en 4Geeks todos los assets con React» o equivalentes que indiquen una tecnología.

Consulta `SKILL.md` para el flujo completo. El helper `scripts/get_assets.py` resuelve primero la tecnología pública canónica y después obtiene todos los assets paginados asociados a ese slug. La respuesta se resume en Telegram; el detalle y la explicación de campos se preparan en Google Docs mediante Zapier, sin duplicar ni sobrescribir documentos.

El catálogo es público y no representa tareas asignadas ni recursos específicos de la cohorte de Ruth. El documento incluye metadatos y enlaces públicos disponibles, no necesariamente el contenido completo del asset.
